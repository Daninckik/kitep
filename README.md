# ГИС «Китеп» — платформа учебников Кыргызской Республики

Государственная информационная система для создания, редактирования, анализа,
согласования и публикации школьных учебников КР. Включает прежний модуль
проверки книг по Закону КР № 185 (доступен по адресу `/checker`).

## Запуск

```
pip install -r requirements.txt
python -m uvicorn app:app --host 0.0.0.0 --port 8077
```

Открыть: http://127.0.0.1:8077. С других компьютеров сети: `http://<IP-этого-ПК>:8077`
(если не открывается — разрешите python в брандмауэре Windows).

Сейчас включён режим разработки без входа (auth.py: `DEV_AUTO_LOGIN`) — все
работают как суперадминистратор. Для включения авторизации: `DEV_AUTO_LOGIN=0`;
вход: **admin / admin123** (пароль первого запуска — переменная `ADMIN_PASSWORD`).
AI-ключ задаётся в «Администрирование → OCR / AI» или переменной `ANTHROPIC_API_KEY`.

Docker: `docker compose up -d --build` (ключ AI берётся из переменной окружения
`ANTHROPIC_API_KEY` или файла `.env`).

## Возможности

- **Конструктор учебников** — структура по образцу государственных изданий
  (kitep.edu.kg): титульный лист, авторский коллектив, главы → параграфы/уроки
  (цели обучения, текст, задания, домашние задания, контрольные вопросы,
  итоговое тестирование), словарь терминов, литература, приложения, QR-коды.
  Автосохранение, версии с восстановлением, история изменений, комментарии.
- **Государственные страницы** — гимн, герб и флаг КР автоматически включаются
  в печатную версию (изображения в `static/img/` — стилизация; для тиража
  заменить официальными файлами).
- **Совместная работа** — участники книги (авторы, соавторы, редакторы,
  корректоры, рецензенты), все действия фиксируются в истории.
- **Согласование** — маршрут: черновик → редактура → методист → юрист →
  рецензент → Министерство → гриф → публикация. Каждый этап — своя роль.
- **12 ролей** — от суперадминистратора до наблюдателя (`permissions.py`).
- **OCR-модуль** — PDF, DOCX, JPG, PNG, TIFF и др.; сканы распознаются
  Tesseract (кыргызский, русский, английский), включая таблицы и подписи.
- **AI-анализ** — Claude (claude-opus-4-8) оценивает: учебник ли это,
  соответствие стандартам КР и структуре госизданий, наличие обязательных
  разделов, оформление, полноту; даёт процент соответствия и рекомендации.
- **Статистика** — учебники по классам/предметам, пользователи, AI-метрики
  (успешность, среднее время) и расход токенов по пользователям и книгам.
- **Админ-панель** (Администрирование) — пользователи; редактируемая матрица
  прав ролей (суперадмин); управление учебниками (принудительный статус,
  удаление); справочники предметов и классов; образовательные стандарты КР
  (их тексты автоматически подставляются в AI-анализ по предмету); госшаблоны
  (тексты гимна, замена изображений герба/флага); настройки OCR (языки, лимит
  страниц) и AI (модель, ключ, объём текста); журнал действий и глобальная
  история изменений; резервное копирование БД (создание, скачивание,
  восстановление — только суперадмин).
- **Экспорт/импорт** — файл `.kitep.json`; печатная версия (PDF — через
  диалог печати браузера).

## Структура

- `app.py` — FastAPI-приложение, маршруты чекера, статика
- `db.py` — SQLite (`data/kitep.db`), схема
- `auth.py`, `permissions.py` — сессии, роли, права, маршрут согласования
- `books_api.py` — конструктор: CRUD, версии, комментарии, согласование
- `ai_api.py` — OCR + AI-анализ (Claude, учёт токенов и стоимости)
- `stats_api.py`, `admin_api.py` — статистика и админка
- `state_pages.py` — гимн/герб/флаг КР
- `analyzer.py`, `rules.py`, `extractors.py` — модуль проверки по Закону № 185
- `static/platform.*` — фронтенд платформы; `static/index.html` — чекер

## Важно

Система адаптирована под законодательство и образовательные стандарты КР
(ТЗ п.11): структура учебников — по образцу изданий портала kitep.edu.kg,
контент-проверка — по Закону КР № 185, маршрут согласования — по этапам
экспертиз Министерства просвещения КР. AI-анализ и автопроверка —
предварительные инструменты; итоговое решение о грифе принимают экспертизы
Министерства просвещения КР.
